# 伏羲钟 (Fuxi Clock) v1.0

> **伏羲钟学术来源**：  
> 《张远山作品集》第十六卷《伏羲之道：解密华夏文化总基因》第六章  
> 公众号：庄子江湖

《伏羲钟》是一款基于中国上古天文学与神农归藏历的古典日历与心笺笔记应用。应用严格遵循张远山先生考证的伏羲双圈圆图与神农归藏历分卦值日法，将二十四节气天行度数、七十二候物候印谱、帛书周易六十四卦当值爻辞以及古籍刻本信笺笔记本融为一体。

---

## 🏛️ 核心架构与三大功能模块

### 一、「印」—— 七十二候印谱
* **物候印谱全幅高清呈现**：收录七十二候经典物候刻印，以纯粹古籍书口形式呈现。
* **时令结界**：严格以节气为单位，仅允许在当令三候内翻阅研习。试图跨节气翻阅时，触发时令结界保护，动态提示当令节气、今日斗柄所指当值卦象及邻近节气。

### 二、「钟」—— 伏羲钟天文星历盘面
* **神农归藏历双圈圆图**：
  * **外圈四正卦**：乾（午/南/夏至）、坤（子/北/冬至）、泰（卯/东/春分）、否（酉/西/秋分），各主二至二分用事之日；
  * **内圈六十卦**：360 爻严格遵循“一爻主一日”，360 日周天流转；
  * **太极阴阳双龙交尾钟盘**：实时展示当日指针针位、圆周度数与节气天数。
* **三行天文实景纪实**：
  1. `今日立针 · [节气]第N日 · [度数]°`
  2. `[月建纪实] · 招摇指[地支] · 斗柄指[当值卦]卦`
  3. `[太阳行度与天象实录]`
* **交互探索**：支持手势拨盘探赜、岁序周流动态演示及双指缩放查看高精度天文刻度。

### 三、「笺」—— 古籍刻本信笺笔记本
* **经典古籍筒子页版式**：矩形四周外粗内细双墨线边框、左右对称黑鱼尾书口（版心）、蓝丝栏竖排格。
* **帛书周易值日卦爻**：
  * 每日根据神农归藏历自动翻开当值周易卦象；
  * 呈现帛书周易原版卦名、卦辞，以及今日当值爻之帛书经文；
  * 周易六爻卦象图符中，今日当值之爻以古典朱砂红鲜明高亮。
* **提笔录墨**：
  * 点开信笺支持横向自如打字录入，落墨后自动依古法自右向左排入十行蓝丝栏竖格；
  * 支持多页自动折页、左右滑屏翻阅叶码、书斋号个性题签及一键古典书影导出分享。

## 📐 神农归藏历 · 分卦值日历法数理机制

根据汉代孟康《汉书注》：“分卦值日之法，一爻主一日，六十卦为三百六十日。余四卦……是二至二分用事之日，又是四时。”

1. **内圈六十卦**：共 360 爻，一爻主一日，每卦 6 日，四季各 15 卦（90日），合计 360 日。
2. **外圈四正卦（乾、坤、泰、否）**：各值 1 日，每季 91 日，四季合计 364 日。
3. **平年归余于终**：冬至坤卦上下卦各计 1 日（坤计 2 日），全年 365 日。
4. **闰年归余于中**：夏至乾卦上下卦各计 1 日（乾计 2 日），全年 366 日。

## 🛠️ 技术栈与编译构建

* **开发语言**：Kotlin
* **UI 框架**：Jetpack Compose & Material 3
* **图像加载**：Coil 2.x
* **中国传统历法引擎**：Lunar (nlf-calendar)
* **最低支持版本**：Android 8.0 (API 26)
* **目标版本**：Android 15 (API 35)

### 构建命令

```bash
# 调试版本编译与安装
./gradlew installDebug

# 发布版本 APK 打包
./gradlew assembleRelease
```
